Язык: Русский (ru)

Упростите работу с merge request в GitLab благодаря автоматизации в один клик. Замените многошаговые ручные операции — rebase, повышение версии, управление пайплайнами и слияние — одной кнопкой. Поддерживаются GitLab на собственном сервере по HTTPS и gitlab.com; доступность функций зависит от возможностей сервера и прав учётной записи. Токены API не нужны — используется ваша текущая сессия браузера.

★ РЕВЬЮ С ИИ В ВАШИХ ПРИВЫЧНЫХ ИНСТРУМЕНТАХ

• Полное ревью MR — подготовьте задание по всем коммитам MR с настраиваемыми фильтрами файлов
• Исправление и ответы — скопируйте выбранные замечания в свой инструмент ИИ для разработки и подготовьте ответы для публикации
• Повторное ревью — перепроверьте исправления и изменения после выбранной ревизии, в том числе после force push
• Редактируемый импорт — вставьте комментарии и ответы ИИ в формате JSON, отредактируйте текст и опубликуйте выбранное либо сохраните черновики ревью. При необходимости закройте обсуждения после публикации ответов
• Свои инструкции — настройте промпты и автоматически добавляемые инструкции, выберите язык ответа
• Ручная передача — используйте любой удобный инструмент ИИ. Расширению не нужны ключи API ИИ; код никуда не загружается автоматически

★ ДЕЙСТВИЯ С MERGE REQUEST

• Автослияние — выполните rebase и включите слияние после успешного пайплайна одним нажатием
• Ship — полный процесс выпуска: повышение версии → пайплайн → автослияние
• Принудительное слияние — слейте MR без ожидания пайплайна, когда CI не нужен
• Повышение версии — увеличьте версию в package.json, pyproject.toml или другом файле: patch / minor / major
• Rebase — перебазируйте ветку с повышением версии или без него
• Черновик / Готово — переключайте статус MR без редактирования заголовка
• Быстрые комментарии — публикуйте шаблонные комментарии к MR одним нажатием
• Копирование MR — мгновенно скопируйте заголовок и ссылку в буфер обмена

★ УПРАВЛЕНИЕ ПАЙПЛАЙНАМИ CI/CD

• Новый пайплайн / Отмена — запускайте и отменяйте пайплайны
• Повтор всех упавших заданий — перезапустите все неуспешные задания последнего пайплайна за один раз
• Свои кнопки заданий — запускайте любое задание CI одним нажатием или объединяйте несколько в цепочку, например сборка → развёртывание
• Просмотр ошибок — названия упавших заданий и строки журнала ошибок прямо на странице MR
• Фоновое выполнение — пользовательские цепочки заданий продолжаются после перехода на другую страницу

★ ИНТЕГРАЦИЯ С JIRA БЕЗ ТОКЕНОВ API

• Значки статусов Jira — цветные статусы задач: готово, в работе, QA, к выполнению. Ключи задач извлекаются из заголовков MR
• Боковая панель задачи — нажмите значок, чтобы увидеть название, статус, исполнителя, приоритет, спринт, эпик, метки, описание и вложения
• Статус и исполнитель — переводите задачи в другой статус и назначайте исполнителя, не покидая GitLab
• Быстрые действия Jira — составные операции, например смена статуса и назначение исполнителя, одним нажатием
• Тип и приоритет — стандартные значки Jira в списке MR и на странице MR
• Поля Jira у коммитов — отображайте Fix Version, статус или другое поле рядом с коммитами
• Jira в ежедневных отчётах — названия задач автоматически добавляются в сводку активности

★ УЛУЧШЕНИЯ СПИСКА MR

• Размер MR — цветные значки S / M / L / XL по количеству изменённых строк
• Индикатор конфликтов — красный значок при конфликтах слияния
• Незакрытые обсуждения — количество открытых обсуждений видно сразу
• Названия веток — исходная → целевая ветка у каждого MR
• Индикатор одобрения — показывает, одобрили ли вы MR
• Приглушение черновиков — помогает сосредоточиться на активных MR
• Подсветка ваших MR — синяя рамка для быстрого поиска
• Переключатели «Только мои», «Ждут моего ревью» и «Группировать по автору»
• Значок «Ваше ревью» — обнаруживает упоминания в настроенном задании ревьюеров и комментариях
• Копирование из списка — кнопка копирования у каждого MR

★ ИНСТРУМЕНТЫ ПРОДУКТИВНОСТИ

• Палитра команд (Cmd+K / Ctrl+K) — переходите к MR, пайплайнам, веткам, задачам или запускайте действия
• Поиск файлов — найдите и откройте файл проекта по имени через палитру
• Ежедневный отчёт — сводка созданных, слитых, прокомментированных и одобренных MR. Копирование для Slack или Jira
• Cherry-pick в несколько веток — переносите коммит сразу в несколько веток с автоматическим созданием MR
• Восстановление cherry-pick — при конфликте повторите перенос коммита без файла версии автоматически
• Предупреждение о важных файлах — оранжевый значок, если MR затрагивает .env, Dockerfile, настройки CI или файлы с учётными данными
• Команды Git — скопируйте git checkout и git fetch для ветки MR
• Возраст MR — показывает, как долго MR остаётся открытым
• Подсветка своих комментариев — цветная рамка вокруг ваших комментариев в обсуждениях

★ НАСТРОЙКА

• Профили проектов — свои кнопки, файлы версий и задания CI для каждого репозитория
• Порядок кнопок — расположите действия перетаскиванием
• Ширина табуляции в diff — 2, 4 или 8 пробелов
• Сворачивание верхних панелей / Скрытие правой панели — больше рабочего пространства
• Звук и уведомления — узнавайте об успехе или ошибке выполнения действий
• Тёмная тема — автоматически следует настройкам системы

✓ Без персональных токенов доступа — используются cookies вашей сессии GitLab
✓ Без сервиса-посредника — запросы GitLab и Jira идут напрямую на настроенные серверы
✓ Поддержка GitLab на собственном сервере по HTTPS и gitlab.com; проверенные контракты API описаны в руководстве по совместимости
✓ Jira без токенов API — используется сессия браузера
✓ Гибкая настройка для каждого проекта
✓ Лёгкое расширение — фоновые проверки выполняются для запущенных вами действий; без телеметрии и автоматической передачи кода в ИИ
✓ Интерфейс доступен на 27 языках
✓ Открытый исходный код
