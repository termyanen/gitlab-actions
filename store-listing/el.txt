Απλοποιήστε τη ροή εργασίας των αιτημάτων συγχώνευσης στο GitLab με αυτοματοποίηση με ένα μόνο κλικ. Αντικαταστήστε τις πολύπλοκες χειροκίνητες ενέργειες — rebase, αύξηση έκδοσης, διαχείριση pipeline και συγχώνευση — με ένα μόνο κουμπί. Υποστηρίζει HTTPS self-hosted GitLab και gitlab.com· η διαθεσιμότητα εξαρτάται από τις δυνατότητες του διακομιστή και τα δικαιώματα του λογαριασμού. Δεν απαιτούνται API tokens — χρησιμοποιεί την υπάρχουσα συνεδρία του προγράμματος περιήγησής σας.

★ AI ΑΝΑΣΚΟΠΗΣΗ ΜΕ ΤΑ ΔΙΚΑ ΣΑΣ ΕΡΓΑΛΕΙΑ

• Πλήρης ανασκόπηση MR — ετοιμάστε ένα έργο που καλύπτει όλα τα commits του MR, με ρυθμιζόμενα φίλτρα αρχείων
• Διόρθωσε και απάντησε — αντέγραψε τα επιλεγμένα σχόλια στο AI σου για κώδικα και ετοίμασε απαντήσεις έτοιμες για δημοσίευση
• Επαναληπτικός έλεγχος — ξαναέλεγξε τις διορθώσεις και αλλαγές από μια επιλεγμένη αναθεώρηση, ακόμα και μετά από force pushes
• Επεξεργάσιμη εισαγωγή — επικόλλησε σχόλια και απαντήσεις του AI ως JSON, επεξεργάσου το κείμενό τους και δημοσίευσε επιλεγμένα στοιχεία ή αποθήκευσε προσχέδια αναθεώρησης. Προαιρετικά, λύσε συζητήσεις μετά τη δημοσίευση απαντήσεων
• Προσαρμοσμένες οδηγίες — προσαρμόστε prompts και αυτόματα μπλοκ οδηγιών· επίλεξε τη γλώσσα της απάντησης
• Χειροκίνητη κοινή χρήση — χρησιμοποίησε το προτιμώμενο εργαλείο AI σου. Κανένα κλειδί API AI στην επέκταση και καμία αυτόματη αποστολή κώδικα

★ ΕΝΕΡΓΕΙΕΣ ΑΙΤΗΜΑΤΟΣ ΣΥΓΧΩΝΕΥΣΗΣ

• Αυτόματη συγχώνευση — εκτέλεσε rebase και ενεργοποίησε το «συγχώνευση όταν επιτύχει το pipeline» με ένα κλικ
• Δημοσίευση — πλήρης ροή κυκλοφορίας: αύξηση έκδοσης → pipeline → αυτόματη συγχώνευση, όλα αυτοματοποιημένα
• Εξαναγκασμένη συγχώνευση — παράβλεψε το pipeline και συγχώνευσε αμέσως όταν δεν χρειάζεται CI
• Αύξηση έκδοσης — ανέβασε την έκδοση στο package.json, pyproject.toml ή σε οποιοδήποτε αρχείο (patch / minor / major)
• Rebase — κάνε rebase του branch με ή χωρίς αύξηση έκδοσης
• Εναλλαγή Πρόχειρο / Έτοιμο — άλλαξε το status του MR χωρίς να επεξεργαστείς τον τίτλο
• Γρήγορα σχόλια — δημοσίευσε πρότυπα σχολίων στο MR με ένα κλικ
• Αντιγραφή MR — αντιγράψε τίτλο + σύνδεσμο στο πρόχειρο αμέσως

★ ΕΛΕΓΧΟΙ CI/CD PIPELINE

• Νέο pipeline / Ακύρωση pipeline — δημιούργησε ή ακύρωσε pipeline αμέσως
• Επανάληψη αποτυχημένων εργασιών — ξανάρχισε κάθε αποτυχημένη εργασία στο τελευταίο pipeline ταυτόχρονα
• Προσαρμοσμένα κουμπιά εργασιών — εκκίνησε οποιαδήποτε CI εργασία με ένα κλικ· αλυσίδωσε πολλές εργασίες (π.χ. build → deploy)
• Γρήγορη επισκόπηση αποτυχημένων εργασιών — δείτε ονόματα αποτυχημένων εργασιών και γραμμές καταγραφής σφαλμάτων απευθείας στη σελίδα MR
• Εκτέλεση στο παρασκήνιο — οι προσαρμοσμένες αλυσίδες εργασιών συνεχίζονται μετά τη μετάβαση σε άλλη σελίδα

★ ΕΝΣΩΜΑΤΩΣΗ JIRA (χωρίς API tokens)

• Σήματα κατάστασης Jira — χρωματικά κωδικοποιημένες καταστάσεις ζητημάτων (Ολοκληρώθηκε, Σε Εξέλιξη, QA, Να γίνει) αντλούνται από τους τίτλους MR
• Πλήρης πλευρική γραμμή ζητήματος — κάντε κλικ σε οποιοδήποτε σήμα για να δείτε περίληψη, κατάσταση, υπεύθυνο, προτεραιότητα, sprint, epic, ετικέτες, περιγραφή και συνημμένα
• Αλλαγή κατάστασης & υπεύθυνου — μεταβείτε μεταξύ καταστάσεων ζητημάτων και αναθέστε ξανά χωρίς να φύγετε από το GitLab
• Γρήγορες ενέργειες Jira — σύνθετες ενέργειες (αλλαγή κατάστασης + ανάθεση) με ένα κλικ
• Εικονίδια τύπου θέματος & προτεραιότητας — εγγενή εικονίδια Jira στη λίστα MR και στις σελίδες λεπτομερειών
• Σήματα πεδίων Jira στα commits — δείξε την έκδοση διόρθωσης, την κατάσταση ή οποιοδήποτε πεδίο δίπλα στα commits
• Εμπλουτισμός Jira στις καθημερινές αναφορές — οι τίτλοι των ζητημάτων προστίθενται αυτόματα στις συνοψίσεις δραστηριοτήτων

★ ΒΕΛΤΙΩΣΕΙΣ ΛΙΣΤΑΣ MR

• Ετικέτες μεγέθους MR — σήματα S / M / L / XL με χρώματα ανάλογα με τις αλλαγές γραμμών
• Δείκτης συγκρούσεων — κόκκινο σήμα όταν ο κλάδος έχει συγκρούσεις συγχώνευσης
• Αριθμός ανεπίλυτων συζητήσεων — δες ανοιχτά θέματα συζήτησης με μια ματιά
• Ονόματα κλάδων — πηγή → στόχος κλάδου εμφανίζονται σε κάθε MR
• Δείκτης έγκρισης — δείχνει αν έχεις εγκρίνει κάθε MR
• Αχνά προσχέδια MR — οπτικά ξεθωριασμένα για να εστιάζεις στα ενεργά merge requests
• Τόνισε τα MR σου — μπλε περίγραμμα στα δικά σου MR για γρήγορη αναγνώριση
• Διακόπτες "Μόνο δικά μου" / "Απαιτεί τη δική μου ανασκόπηση" / "Ομαδοποίηση κατά συντάκτη"
• Σήμα 'Η αξιολόγησή σας' — ανιχνεύει ρυθμισμένες αναφορές αξιολογητή και αναφορές σχολίων
• Αντιγραφή MR από τη λίστα — κουμπί αντιγραφής σε κάθε στοιχείο MR

★ ΕΡΓΑΛΕΙΑ ΠΑΡΑΓΩΓΙΚΟΤΗΤΑΣ

• Παλέτα εντολών (Cmd+K / Ctrl+K) — πλοήγηση στη λίστα MR, pipelines, branches, issues, ή ενεργοποίηση ενεργειών
• Αναζήτηση αρχείου στην παλέτα — βρες και άνοιξε οποιοδήποτε αρχείο έργου με βάση το όνομά του
• Ημερήσια αναφορά δραστηριότητας — περίληψη των MR που δημιουργήθηκαν, συγχωνεύθηκαν, σχολιάστηκαν, εγκρίθηκαν. Αντιγραφή στο Slack ή Jira
• Cherry-pick σε πολλαπλά branches — cherry-pick οποιοδήποτε commit σε διάφορα branches ταυτόχρονα με αυτόματη δημιουργία MR
• Έξυπνη εναλλακτική cherry-pick — επαναλαμβάνει αυτόματα το commit εξαιρώντας το αρχείο έκδοσης σε περίπτωση σύγκρουσης
• Προειδοποίηση ευαίσθητου αρχείου — πορτοκαλί σήμα όταν το MR αγγίζει .env, Dockerfile, ρυθμίσεις CI ή διαπιστευτήρια
• Κουμπιά εντολών Git — αντιγράψτε τις εντολές git checkout και git fetch για το branch του MR
• Σήμα ηλικίας MR — δείτε πόση ώρα είναι ανοιχτό ένα merge request
• Επισημάνετε τα σχόλιά μου — χρωματιστό περίγραμμα στα δικά σας σχόλια στις συζητήσεις

★ ΠΡΟΣΑΡΜΟΓΗ

• Προφίλ ανά έργο — διαφορετικά κουμπιά, αρχεία έκδοσης και εργασίες CI για κάθε αποθετήριο
• Ταξινόμηση κουμπιών με drag & drop — τακτοποιήστε τα κουμπιά ενέργειας όπως σας αρέσει
• Διαμορφώσιμο πλάτος tab στις διαφορές — ρυθμίστε την εμφάνιση tab σε 2, 4 ή 8 κενά
• Συμπτύξτε τις πάνω μπάρες / Κρύψτε τη δεξιά πλαϊνή μπάρα — μεγιστοποιήστε τον χώρο εργασίας σας
• Ηχητικές & επιτραπέζιες ειδοποιήσεις — ενημερωθείτε όταν ολοκληρωθούν ή αποτύχουν ενέργειες
• Σκοτεινό θέμα — ακολουθεί αυτόματα τις προτιμήσεις του συστήματος
