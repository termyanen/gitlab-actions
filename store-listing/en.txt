Streamline your GitLab merge request workflow with one-click automation. Replace multi-step manual operations — rebase, version bump, pipeline management, and merging — with a single button. Supports HTTPS self-hosted GitLab and gitlab.com; availability depends on server capabilities and account permissions. No API tokens required — uses your existing browser session.

★ AI REVIEW WITH YOUR OWN TOOLS

• Full MR review — prepare a task covering all MR commits with file filters and optional context from existing discussions
• Fix and reply — copy selected feedback to your coding AI and prepare ready-to-post replies
• Follow-up review — recheck fixes and changes since a selected revision, including after force pushes
• Editable import — paste AI comments and replies as JSON, edit their text, and publish selected items or save review drafts. Optionally resolve discussions after publishing replies
• Review controls — collapse long comments, expand all, track publication progress and retry confirmed unsent items without duplicating published comments or drafts. For large MRs, try additional diff sources; missing file or line targets can be explicitly converted to general comments
• Custom instructions — customize prompts and automatic instruction blocks; choose the response language
• Manual sharing — use your preferred AI tool. No AI API keys in the extension and no automatic code uploads

★ MERGE REQUEST ACTIONS

• Auto-merge — rebase and enable "merge when pipeline succeeds" in one click
• Ship — full release flow: version bump → pipeline → auto-merge, all automated
• Force merge — request an immediate merge without waiting for the pipeline; GitLab permissions and merge rules still apply
• Version bump — patch / minor / major for configured JSON, TOML or plain-text version files
• Rebase — rebase branch with or without version bump
• Draft / Ready toggle — switch MR status without editing the title
• Quick comments — post template comments to MR with one click
• Copy MR — copy title + link to clipboard instantly

★ CI/CD PIPELINE CONTROLS

• New pipeline / Cancel pipeline — create or cancel pipelines instantly
• Retry all failed jobs — restart every failed job in the latest pipeline at once
• Custom job buttons — trigger any CI job with one click; chain multiple jobs (e.g. build → deploy)
• Failed job quick view — see failed job names and error log lines directly on the MR page
• Background job chains — resume tracking after worker restarts; keep a signed-in tab on the same GitLab site open for API access

★ JIRA SERVER / DATA CENTER (browser session, optional site access)

• Jira status badges — color-coded ticket statuses (Done, In Progress, QA, To Do) parsed from MR titles
• Full ticket sidebar — click any badge to see summary, status, assignee, priority, sprint, epic, labels, description, and attachments
• Change status & assignee — transition tickets and reassign without leaving GitLab
• Jira quick actions — composite actions (change status + assign) with one click
• Issue type & priority icons — native Jira icons on MR list and detail pages
• Jira field badges on commits — show Fix Version, status, or any field next to commits
• Jira enrichment in daily reports — ticket titles added automatically to activity summaries
• Connection check — view the configured Jira domain, check the session and open a sign-in link. Jira Cloud is not fully supported; fields and actions depend on server capabilities and permissions

• Conflicts indicator — red badge when branch has merge conflicts
• Unresolved threads count — see open discussion threads at a glance

★ PRODUCTIVITY TOOLS

• Command palette (Cmd+K / Ctrl+K) — navigate to MR list, pipelines, branches, issues, or trigger actions
• File search in palette — find and open any project file by name
• Daily activity report — summary of MRs created, merged, commented, approved. Copy to Slack or Jira
• Cherry-pick to multiple branches — transfer a commit directly or create MRs; choose shared or per-project target branches
• Smart cherry-pick — three-way text merging with optional target-branch version bump, even without conflicts. Synchronize package.json and package-lock.json root package versions; conflicting non-version edits stop the operation. No bump-only duplicate when there are no new changes to apply
• Sensitive file warning — orange badge when MR touches .env, Dockerfile, CI configs, or credentials
• Git command buttons — copy git checkout and git fetch commands for the MR branch
• MR age badge — see how long a merge request has been open
• Highlight my comments — colored border on your own comments in discussions

★ CUSTOMIZATION

• Settings workspace — searchable full page and inline sections in the compact popup, autosave feedback, JSON import/export and light/dark themes. Toolbar button changes apply without reloading the MR
• Drag & drop button order — arrange action buttons the way you prefer
