Язык: Китайский (упрощённый) (zh_CN)

通过一键自动化简化 GitLab 合并请求工作流。将 rebase、版本更新、流水线管理和合并等多步手动操作整合为一个按钮。支持通过 HTTPS 访问的自托管 GitLab 和 gitlab.com；具体功能取决于服务器能力和账户权限。无需 API 令牌，直接使用现有的浏览器会话。

★ 使用您自己的工具进行 AI 审查

• 完整 MR 审查 — 为 MR 的所有提交生成审查任务，并支持自定义文件过滤条件
• 修复与回复 — 将选中的反馈复制到编程 AI 工具，准备可直接发布的回复
• 后续审查 — 重新检查指定版本之后的修复和变更，也适用于强制推送之后
• 可编辑导入 — 将 AI 评论和回复作为 JSON 粘贴，编辑内容后发布选中条目，或保存为审查草稿。发布回复后可选择将讨论标记为已解决
• 自定义指令 — 调整提示词和自动添加的指令块，并选择回复语言
• 手动共享 — 使用您偏好的 AI 工具。扩展不需要 AI API 密钥，也不会自动上传代码

★ 合并请求操作

• 自动合并 — 一键执行 rebase，并启用“流水线成功后合并”
• Ship — 自动执行完整发布流程：版本更新 → 流水线 → 自动合并
• 强制合并 — 不需要 CI 时，无需等待流水线完成即可合并
• 版本更新 — 更新 package.json、pyproject.toml 或其他文件中的版本号：patch / minor / major
• Rebase — 对分支执行 rebase，可选择是否同时更新版本
• 草稿 / 就绪 — 无需编辑标题即可切换 MR 状态
• 快捷评论 — 一键向 MR 发布模板评论
• 复制 MR — 立即将标题和链接复制到剪贴板

★ CI/CD 流水线控制

• 新建 / 取消流水线 — 直接创建或取消流水线
• 重试所有失败任务 — 一次性重新运行最新流水线中的所有失败任务
• 自定义任务按钮 — 一键触发任意 CI 任务，也可串联多个任务，例如构建 → 部署
• 失败任务速览 — 直接在 MR 页面查看失败任务名称和错误日志行
• 后台执行 — 自定义任务链在切换页面后仍会继续运行

★ JIRA 集成：无需 API 令牌

• Jira 状态徽标 — 从 MR 标题提取工单键，并以颜色区分完成、进行中、QA、待办等状态
• 完整工单侧栏 — 点击徽标即可查看标题、状态、负责人、优先级、冲刺、史诗、标签、描述和附件
• 修改状态和负责人 — 无需离开 GitLab，即可切换工单状态或重新分配负责人
• Jira 快捷操作 — 一键执行状态修改和分配负责人等组合操作
• 类型与优先级图标 — 在 MR 列表和详情页显示 Jira 原生图标
• 提交旁的 Jira 字段 — 在提交旁显示 Fix Version、状态或其他字段
• 日报中的 Jira 信息 — 自动在活动摘要中补充工单标题

★ MR 列表增强

• MR 大小 — 根据修改行数显示彩色 S / M / L / XL 徽标
• 冲突提示 — 分支存在合并冲突时显示红色徽标
• 未解决讨论数量 — 一眼查看尚未解决的讨论数
• 分支名称 — 在每个 MR 上显示源分支 → 目标分支
• 批准提示 — 显示您是否已批准该 MR
• 淡化草稿 — 降低草稿 MR 的视觉突出程度，专注于活跃的合并请求
• 高亮自己的 MR — 使用蓝色边框便于快速识别
• “仅我的”“需要我审查”“按作者分组”开关
• “您的审查”徽标 — 检测已配置的审查者任务及评论中的提及
• 从列表复制 — 每个 MR 均提供复制按钮

★ 效率工具

• 命令面板（Cmd+K / Ctrl+K）— 跳转至 MR、流水线、分支、议题，或触发操作
• 文件搜索 — 在命令面板中按名称查找并打开项目文件
• 每日活动报告 — 汇总创建、合并、评论和批准的 MR，可复制到 Slack 或 Jira
• 向多个分支执行 cherry-pick — 同时将一个提交应用到多个分支，并自动创建 MR
• Cherry-pick 回退 — 遇到冲突时，自动排除版本文件并重新应用提交
• 敏感文件警告 — MR 涉及 .env、Dockerfile、CI 配置或凭据文件时显示橙色徽标
• Git 命令 — 复制 MR 分支的 git checkout 和 git fetch 命令
• MR 存续时间 — 查看合并请求已打开多久
• 高亮自己的评论 — 为讨论中自己的评论添加彩色边框

★ 自定义

• 项目配置 — 为每个仓库设置不同的按钮、版本文件和 CI 任务
• 拖放排序 — 按喜好排列操作按钮
• 差异视图的制表符宽度 — 设置为 2、4 或 8 个空格宽度
• 折叠顶部栏 / 隐藏右侧栏 — 扩大工作区域
• 声音与桌面通知 — 在操作完成或失败时收到提醒
• 深色主题 — 自动跟随系统偏好

★ 为什么选择 GITLAB MR ACTIONS？

✓ 无需个人访问令牌 — 使用现有 GitLab 会话的 Cookie
✓ 无中间服务 — GitLab 和 Jira 请求直接发送至您配置的服务器
✓ 支持 HTTPS 自托管 GitLab 和 gitlab.com；已测试的 API 契约见兼容性指南
✓ Jira 集成无需 API 令牌 — 使用浏览器会话
✓ 可按项目灵活配置
✓ 轻量 — 后台检查仅针对您启动的操作；无遥测，也不会自动向 AI 上传内容
✓ 界面支持27种语言
✓ 开源

让开发者少花时间在 GitLab 中点击，多花时间编写代码。
