Язык: Корейский (ko)

원클릭 자동화로 GitLab 머지 요청(MR) 워크플로를 간소화하세요. 여러 단계의 수동 작업 — 리베이스, 버전 업데이트, 파이프라인 관리, 머지 — 을 하나의 버튼으로 대체할 수 있습니다. HTTPS로 셀프 호스팅된 GitLab과 gitlab.com을 지원하며, 사용 가능 여부는 서버 기능과 계정 권한에 따라 다릅니다. API 토큰이 필요 없고 기존 브라우저 세션을 사용합니다.

★ 내 도구로 하는 AI 리뷰

• 전체 MR 리뷰 — 모든 MR 커밋을 포함한 작업을 준비하고, 파일 필터 설정 가능
• 수정 및 답변 — 선택한 피드백을 코딩 AI로 복사하고 바로 게시할 답변 준비
• 후속 리뷰 — 선택한 리비전 이후 수정 및 변경 사항 재검토, 강제 푸시 후에도 포함
• 편집 가능한 가져오기 — AI 댓글과 답글을 JSON으로 붙여넣고, 텍스트를 편집한 후 선택한 항목을 게시하거나 검토 초안을 저장할 수 있어요. 원하면 답글을 게시한 후 토론을 종료할 수도 있어요.
• 맞춤형 지침 — 프롬프트와 자동 지시 블록을 개인화하고, 응답 언어를 선택할 수 있어요.
• 수동 공유 — 좋아하는 AI 도구를 사용하세요. 확장 프로그램에서는 AI API 키를 사용하지 않으며 코드가 자동으로 업로드되지 않아요.

★ 병합 요청 액션

• 자동 병합 — 한번의 클릭으로 리베이스하고 '파이프라인 성공 시 병합' 기능을 활성화할 수 있어요.
• 배포 — 전체 릴리스 플로우: 버전 올리기 → 파이프라인 → 자동 병합, 모두 자동화돼 있어요.
• 강제 병합 — CI가 필요하지 않을 때 파이프라인 건너뛰고 바로 병합할 수 있어요.
• 버전 올리기 — package.json, pyproject.toml, 또는 다른 파일에서 버전 증가 (패치 / 마이너 / 메이저)
• 리베이스 — 버전 올림 여부 상관없이 브랜치 리베이스
• 초안 / 준비 완료 토글 — 제목 편집 없이 MR 상태 전환
• 빠른 댓글 — 한 번 클릭으로 MR에 템플릿 댓글 남기기
• MR 복사 — 제목 + 링크를 즉시 클립보드로 복사

★ CI/CD 파이프라인 조작

• 새 파이프라인 / 파이프라인 취소 — 파이프라인을 즉시 생성하거나 취소
• 실패한 모든 작업 재시도 — 최신 파이프라인에서 실패한 모든 작업을 한 번에 재시작
• 커스텀 작업 버튼 — 클릭 한 번으로 어떤 CI 작업이든 실행; 여러 작업 연쇄 가능 (예: 빌드 → 배포)
• 실패한 작업 빠른 보기 — MR 페이지에서 바로 실패한 작업 이름과 에러 로그 확인
• 백그라운드 실행 — 페이지 이동 후에도 커스텀 작업 체인 계속 실행

★ JIRA 통합 (API 토큰 필요 없음)

• Jira 상태 배지 — MR 제목에서 파싱한 색상 코딩된 티켓 상태 (완료, 진행 중, QA, 할 일)
• 전체 티켓 사이드바 — 배지를 클릭하면 요약, 상태, 담당자, 우선순위, 스프린트, 에픽, 라벨, 설명, 첨부 파일 확인 가능
• 상태 & 담당자 변경 — GitLab을 떠나지 않고 티켓 전환 및 재할당 가능
• Jira 빠른 액션 — 클릭 한 번으로 상태 변경 + 담당자 지정 같은 복합 액션
• 이슈 유형 & 우선순위 아이콘 — MR 목록 및 상세 페이지에 네이티브 Jira 아이콘 표시
• 커밋에서의 Jira 필드 배지 — 커밋 옆에 Fix Version, 상태 또는 어떤 필드든 표시
• 일일 리포트에서 Jira 정보 강화 — 활동 요약에 티켓 제목 자동 추가

★ MR 리스트 향상

• MR 크기 라벨 — 변경 라인 수에 따라 색상 구분된 S / M / L / XL 배지
• 충돌 표시 — 브랜치에 병합 충돌이 있으면 빨간 배지 표시
• 미해결 스레드 수 — 열린 토론 스레드를 한눈에 확인
• 브랜치 이름 — 각 MR에 소스 → 타겟 브랜치 표시
• 승인 표시 — 각 MR에 승인 여부 표시
• 초안 MR 희미하게 표시 — 활성 MR에 집중하도록 초안 시각적으로 희미화
• 내 MR 강조 — 내 MR에 파란 테두리로 빠르게 식별
• “내 MR만” / “내 검토 필요” / “작성자별로 그룹화” 토글
• “내 리뷰” 배지 — 설정된 리뷰어-작업 언급과 댓글 언급 감지
• 리스트에서 MR 복사 — 각 MR 항목의 복사 버튼

★ 생산성 도구

• 커맨드 팔레트 (Cmd+K / Ctrl+K) — MR 리스트, 파이프라인, 브랜치, 이슈 탐색 또는 액션 실행
• 팔레트 내 파일 검색 — 프로젝트 파일 이름으로 찾고 열기
• 일간 활동 보고서 — 생성, 병합, 댓글, 승인된 MR 요약. Slack이나 Jira로 복사 가능
• 여러 브랜치로 체리픽 — 한 번에 여러 브랜치로 커밋 체리픽, 자동 MR 생성
• 스마트 체리픽 백업 — 충돌 발생 시 버전 파일 제외하고 커밋 자동 재적용
• 민감 파일 경고 — MR이 .env, Dockerfile, CI 설정, 자격 증명 건드리면 주황색 배지 표시
• Git 명령 버튼 — MR 브랜치용 git checkout 및 git fetch 명령 복사
• MR 나이 배지 — 머지 요청이 얼마나 열려 있었는지 확인
• 내 댓글 강조 — 토론에서 본인의 댓글에 색 테두리 표시

★ 맞춤 설정

• 프로젝트별 프로필 — 각 저장소마다 다른 버튼, 버전 파일, CI 작업
• 버튼 순서 드래그 & 드롭 — 원하는 대로 액션 버튼 배치
• diff에서 탭 폭 설정 — 탭 표시를 2, 4, 8 칸 중 선택
• 상단 바 접기 / 오른쪽 사이드바 숨기기 — 작업 공간 최대화
• 소리 & 데스크탑 알림 — 작업 완료나 실패 시 알림 받기
• 다크 테마 — 시스템 환경 설정 자동 적용

★ 왜 GitLab MR Actions인가?

✓ 개인 액세스 토큰 필요 없음 — 기존 GitLab 세션 쿠키 사용
✓ 중간 서비스 필요 없음 — GitLab과 Jira 요청이 구성된 서버로 바로 전송
✓ HTTPS 자체 호스팅 GitLab 및 gitlab.com 지원; 테스트된 API 계약은 호환성 가이드 참조
✓ Jira 통합 시 API 토큰 필요 없음 — 브라우저 세션 쿠키 사용
✓ 프로젝트별 완전 설정 가능 — 모든 프로젝트에 맞는 제한 없음
✓ 가벼움 — 시작한 작업에 대해서만 백그라운드 검사 실행; 원격 데이터 수집이나 자동 AI 업로드 없음
✓ 27개 인터페이스 언어를 지원합니다.
✓ 오픈 소스

GitLab에서 클릭하는 시간을 줄이고 코드 작성에 더 많은 시간을 쓰고 싶은 개발자들이 선택한 확장 프로그램입니다.
