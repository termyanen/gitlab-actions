Язык: Малайский (ms)

Permudahkan aliran kerja merge request GitLab anda dengan automasi satu klik. Gantikan operasi manual berbilang langkah — rebase, peningkatan versi, pengurusan pipeline, dan penggabungan — dengan satu butang. Menyokong GitLab self-hosted HTTPS dan gitlab.com; ketersediaan bergantung pada kemampuan server dan izin akaun. Tiada token API diperlukan — menggunakan sesi pelayar semasa anda.

★ ULASAN AI DENGAN ALAT ANDA SENDIRI

• Ulasan MR penuh — sediakan tugas merangkumi semua commit MR, dengan penapis fail yang boleh dikonfigurasi
• Baiki dan balas — salin maklum balas yang dipilih ke AI pengekodan anda dan sediakan balasan sedia untuk dipos
• Semakan susulan — semak semula pembaikan dan perubahan sejak semakan terpilih, termasuk selepas force push
• Import boleh sunting — tampal komen dan balasan AI sebagai JSON, sunting teks mereka, dan terbitkan item terpilih atau simpan draf semakan. Pilihan untuk menyelesaikan perbincangan selepas menerbitkan balasan
• Arahan tersuai — sesuaikan arahan dan blok arahan automatik; pilih bahasa balasan
• Perkongsian manual — guna alat AI pilihan anda. Tiada kunci API AI dalam sambungan dan tiada muat naik kod automatik

★ TINDAKAN PERMINTAAN GABUNGAN

• Gabung automatik — rebase dan dayakan "merge apabila pipeline berjaya" dalam satu klik
• Hantar — aliran pelepasan penuh: naik versi → pipeline → gabung automatik, semua automatik
• Paksa gabung — langkau pipeline dan gabungkan segera apabila CI tidak diperlukan
• Tingkatkan versi — tingkatkan versi dalam package.json, pyproject.toml, atau mana-mana fail (patch / minor / major)
• Rebase — rebase cawangan dengan atau tanpa peningkatan versi
• Tukar Draf / Sedia — tukar status MR tanpa mengedit tajuk
• Komen cepat — hantarkan komen template kepada MR dengan satu klik
• Salin MR — salin tajuk + pautan ke papan klip serta-merta

★ KAWALAN SALURAN CI/CD

• Pipeline baru / Batalkan pipeline — buat atau batalkan pipeline serta-merta
• Cuba semula semua kerja gagal — mulakan semula setiap kerja yang gagal dalam pipeline terbaru sekaligus
• Butang kerja tersuai — aktifkan mana-mana kerja CI dengan satu klik; rantai pelbagai kerja (contoh: bina → laksanakan)
• Paparan pantas kerja gagal — lihat nama kerja yang gagal dan bar log ralat terus di halaman MR
• Pelaksanaan latar belakang — rangkaian kerja tersuai diteruskan selepas navigasi halaman

★ INTEGRASI JIRA (tanpa token API)

• Lencana status Jira — status tiket berwarna (Selesai, Sedang Berjalan, QA, Perlu Dilakukan) diparse daripada tajuk MR
• Bar sisi tiket penuh — klik mana-mana lencana untuk melihat ringkasan, status, pemegang tugas, keutamaan, pecutan, epik, label, penerangan, dan lampiran
• Tukar status & pemegang tugas — transisi tiket dan tugaskan semula tanpa meninggalkan GitLab
• Tindakan pantas Jira — tindakan komposit (tukar status + tugaskan) dengan satu klik
• Ikon jenis isu & keutamaan — ikon Jira asli pada senarai MR dan halaman terperinci
• Lencana medan Jira pada komit — tunjukkan Versi Pembetulan, status, atau mana-mana medan di sebelah komit
• Pemerkayaan Jira dalam laporan harian — tajuk tiket ditambah secara automatik pada ringkasan aktiviti

★ PENAMBAHBAIKAN SENARAI MR

• Lencana saiz MR — lencana S / M / L / XL berwarna mengikut bilangan baris yang diubah
• Penunjuk konflik — lencana merah apabila cawangan mempunyai konflik penggabungan
• Kiraan thread yang belum diselesaikan — lihat thread perbincangan terbuka dengan sekilas pandang
• Nama cawangan — cawangan sumber → sasaran dipaparkan pada setiap MR
• Penunjuk kelulusan — menunjukkan sama ada anda telah meluluskan setiap MR
• Pudar MR Draf — pudar secara visual draf untuk memfokus pada permintaan penggabungan aktif
• Sorot MR anda — sempadan biru pada MR anda sendiri untuk pengenalan cepat
• Togol "Hanya milik saya" / "Memerlukan semakan saya" / "Kumpul mengikut pengarang"
• Lencana "Ulasan anda" — mengesan sebutan pekerjaan-pemeriksa yang dikonfigurasi dan sebutan komen
• Salin MR dari senarai — butang salin pada setiap item MR

★ ALAT PRODUKTIVITI

• Palet perintah (Cmd+K / Ctrl+K) — navigasi ke senarai MR, pipeline, cawangan, isu, atau tindakan pencetus
• Carian fail dalam palet — cari dan buka mana-mana fail projek mengikut nama
• Laporan aktiviti harian — ringkasan MR yang dibuat, digabungkan, dikomen, diluluskan. Salin ke Slack atau Jira
• Pilih-cherry ke pelbagai cawangan — pilih-cherry sebarang komit ke beberapa cawangan sekaligus dengan penciptaan MR automatik
• Pilih-cherry pintar sandaran — main semula komit secara automatik kecuali fail versi jika berlaku konflik
• Amaran fail sensitif — lencana oren apabila MR menyentuh .env, Dockerfile, konfigurasi CI, atau kelayakan
• Butang arahan Git — salin arahan git checkout dan git fetch untuk cawangan MR
• lencana umur MR — lihat berapa lama permintaan gabungan telah dibuka
• Serlahkan komen saya — sempadan berwarna pada komen anda sendiri dalam perbincangan

★ PENYESUAIAN

• Profil setiap projek — butang, fail versi, dan tugas CI yang berbeza untuk setiap repositori
• Seret & lepas susunan butang — susun butang tindakan mengikut kesukaan anda
• Lebar tab boleh dikonfigurasikan dalam perbezaan — tetapkan paparan tab kepada 2, 4, atau 8 ruang
• Sembunyikan bar atas / Sembunyikan bar sisi kanan — maksimumkan kawasan kerja anda
• Bunyi & notifikasi desktop — diberitahu apabila tindakan selesai atau gagal
• Tema gelap — mengikuti keutamaan sistem secara automatik

★ MENGAPA TINDAKAN MR GITLAB?

✓ Tiada token akses peribadi — menggunakan kuki sesi GitLab anda yang sedia ada
✓ Tiada perkhidmatan perantara — permintaan GitLab dan Jira pergi terus ke pelayan yang anda telah konfigurasikan
✓ Menyokong GitLab sendiri yang HTTPS dan gitlab.com; lihat panduan keserasian untuk kontrak API yang diuji
✓ Integrasi Jira tanpa token API — menggunakan kuki sesi pelayar
✓ Boleh dikonfigurasikan sepenuhnya bagi setiap projek — tiada had saiz-semuanya
✓ Ringan — pemeriksaan latar dijalankan untuk tindakan yang anda mulakan; tiada telemetri atau muat naik AI automatik
✓ Tersedia dalam 27 bahasa antara muka
✓ Sumber terbuka

Dipercayai oleh pembangun yang ingin menghabiskan lebih sedikit masa mengklik melalui GitLab dan lebih banyak masa menulis kod.
