# Описания Chrome Web Store

В каждом `<locale>.txt` первая строка на русском обозначает язык. В поле подробного описания магазина копируйте текст **после первой пустой строки**, без подписи языка. Файлы подготовлены локально и не опубликованы.

Исходник — `en.txt`, адаптированный из предоставленного описания: актуализированы число локализаций, ограничения совместимости, фоновые проверки и прямые запросы к Jira/GitLab. Список возможностей сохранён. Название и краткое описание берите из `extName` и `extDescription` соответствующего `_locales/<locale>/messages.json`.

Переводы подготовлены с помощью ИИ и машинного перевода, с редактурой технических обозначений; технические проверки не заменяют редактуру носителем языка. Перед публикацией проверьте терминологию и отображение в предпросмотре магазина. Первая русская строка не является частью публикуемого описания.

Обновляйте все файлы вместе при изменении возможностей или поддерживаемых языков. Длинные руководства и маркетинговый сайт поддерживаются на английском и русском отдельно; наличие локализованного интерфейса не означает перевод сайта на все языки.

См. [правила локализации](../docs/LOCALIZATION.md).
