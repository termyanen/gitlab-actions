GitLab MR Actions

Speed up your merge request workflow with one-click actions.

Quick start

  1. Open any Merge Request page Navigate to any MR on your GitLab instance (self-hosted or gitlab.com)
  2. See action buttons appear Buttons will show at the bottom of the MR widget area. We enabled the most popular ones for you.
  3. Customize via extension popup Click the extension icon to enable/disable buttons, set version bump file, add custom job buttons, and more.

Enabled by default

Auto-merge

Rebase the branch (if needed) and enable merge when pipeline succeeds.

New pipeline

Create a fresh pipeline for the source branch with one click.

Cancel pipeline

Cancel all running pipelines on the MR instantly.

Draft toggle

Switch MR between Draft and Ready status without editing the title.

More actions (enable in settings)

Version bump

Increment version in package.json, pyproject.toml, or any custom file. Configurable strategy (patch/minor/major).

Rebase

Rebase the source branch onto the target branch without merging.

Rebase + Version

Rebase the branch and bump version in one click. Does not merge.

Ship (Version + Merge)

Bump version, wait for pipeline, auto-merge. Full release flow in one click.

Force merge

Skip pipeline and merge immediately. Use with caution.

Reviewers

Repost last reviewer assignment comment or trigger a reviewer pipeline job.

Retry failed jobs

Retry all failed jobs in the latest pipeline. Already succeeded jobs are not affected.

Copy MR

Copy the MR title and link to clipboard with one click.

MR age badge

Shows how long ago the MR was created, displayed as a badge on the MR page.

Conflicts indicator

Shows a red CONFLICTS badge on MR detail page when the branch has merge conflicts.

My approval indicator

Shows whether you have approved each MR on the list page. Distinguishes your approval from approvals by others.

Branch names on MR list

Displays source and target branch names on each MR in the list, so you can see where the code is coming from and where it merges into.

Failed job quick view

When a pipeline fails, shows failed job names and last lines of the error log directly on the MR page. No need to click through to find the error.

Quick comments

Configurable template comment buttons on MR page. Post LGTM, Needs fixes, or any custom comment with one click.

Command palette

Press Cmd+K (Mac) or Ctrl+K (Win) on any GitLab page. Navigate, run MR actions, search files by name and open them in the repo.

Daily activity report

Generate a daily activity report from your GitLab data. Shows created, merged, and reviewed MRs. Copy and paste into Slack or Jira.

Cherry-pick to branches

Cherry-pick any commit to multiple branches at once with real-time status. If a cherry-pick fails due to a version file conflict, the extension automatically retries — it replays the commit without the version file and optionally bumps the version, all in a single commit preserving the original author.

MR list page enhancements

Dim Draft MRs

Visually dim Draft MRs on the merge requests list page so you can focus on active ones.

Highlight your MRs

Highlight your own MRs in the list with a blue border for quick identification.

"Only mine" toggle

One-click toggle to filter the MR list to show only your merge requests.

"Your review" badge

Scans first 10 comments for "Reviewer(s): @you" pattern and shows a badge if you are assigned. Separate from GitLab's built-in reviewer feature.

"Needs my review" toggle

One-click toggle to filter the MR list to show only merge requests where you are assigned as a reviewer.

Copy MR from list

Adds a copy button to each MR on the list page. Copies the MR title and link to clipboard with one click.

Unresolved threads count

Shows a red badge with the number of unresolved discussion threads on each MR in the list.

MR size labels

Color-coded size badges (S/M/L/XL) based on the number of changed lines. S: 1-50, M: 51-200, L: 201-500, XL: 500+.

Jira status badges

Shows Jira ticket statuses on the MR list page. Parses ticket IDs from MR titles (e.g. CCS-1111) and displays colored status badges. Set your Jira URL in settings.

Custom ticket regex

Configure a custom regular expression for parsing Jira ticket IDs from MR titles. Useful for non-standard ticket prefixes.

Jira ticket sidebar

Click any Jira badge to open a sidebar with full ticket details — summary, status, type, priority, assignee, and description. No need to open Jira in a new tab.

Attachments in sidebar

View images, videos, and files from Jira tickets directly in the sidebar. Images and videos open in a fullscreen lightbox.

Jira badges on MR page

Jira ticket status badges are shown in the MR title on the detail page. Click a badge to open the sidebar with full ticket details.

Change Jira status

Change ticket status directly from the sidebar. Shows only available transitions from the current status.

Change Jira assignee

Click the assignee to search and reassign. Autocomplete with avatars, unassign button to remove assignee.

Jira quick actions

Configure composite actions: change status + assign user in one click. Buttons appear in the sidebar when the transition is available.

Issue type & priority icons

Show Jira issue type and priority icons next to status badges on MR list and detail pages. Uses native Jira icons.

UI customization

Collapse top bars

Adds a button to collapse/expand GitLab navigation bars. Saves space and helps you focus on content.

Hide UI sections

Hide right sidebar on MR pages to get full-width content area.

How it works

This extension uses your existing GitLab session (cookies) to call the GitLab API on your behalf. No personal access tokens needed.

  • Works with any self-hosted GitLab instance and gitlab.com
  • Actions use the same permissions as your logged-in user
  • Long-running job chains run in the background and survive page navigation
  • Per-project profiles let you customize buttons for different repositories
You can create per-project profiles in the popup settings. This is useful when different projects need different version files or custom CI jobs.
